# Ask Giorgio — Universal package

Distribution v0.1.1; guide protocol v0.1.0 (unchanged).
Experimental draft, not a validated museum guide. No Museum Packs included.

1. Review protocol.md.
2. Open a new conversation in your own compatible AI service.
3. Attach protocol.md, or paste its contents if file upload is unavailable.
4. Ask: “Read the full attached Ask Giorgio protocol and use it to guide this museum visit. Tell me if you cannot access it. I am at [museum].”
5. Check that the assistant has read it, then try your provider's voice mode if available.

The website cannot install into your AI account automatically. Your provider supplies AI, usage limits, connectivity requirements and privacy controls. A downloadable file does not add reliable offline inference or automatic memory.

Optionally review and fill in ask-giorgio-profile.md, then attach it to a later chat. Save only what you want retained. ZIP downloads are generic; use the website's Copy the guide action to include your selected visit settings.

For a host that supports custom Agent Skills, the separate Skill ZIP contains the ask-giorgio folder with SKILL.md and references. Follow your host's current import instructions; availability depends on the host and plan. Otherwise use the universal protocol above.
